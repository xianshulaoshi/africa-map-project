# 非洲殖民扩张 1870–1914 · 交互地图

根据原始历史地图（Larousse 出版的法语地图 *L'Expansion coloniale en Afrique, 1870–1914*）复刻的交互式网页。
原始图片见 `source-map.png`。

## 打开方式

直接双击打开 `index.html`（无需服务器、无需联网，全部本地资源）。

线上地址（GitHub Pages）：https://xianshulaoshi.github.io/africa-map-project/

## 功能

- **60 个可选中区域**：涵盖 8 个列强（法、英、德、比、葡、西、意、奥斯曼）在非洲的全部殖民地/保护领地，以及利比里亚、阿比西尼亚两个独立国家
- **点击选中 / 多选**：地图或左侧列表均可点击，可任意组合多选，右侧统计合计面积
- **悬停提示**：法语原名、中文名、面积、宗主国、地位
- **选中详情**：获得时期、殖民地位、约面积（km²）、今属国家、首府与图中城市
- **图例筛选**：点击图例中的列强行，仅高亮该国的领地
- **搜索**：支持法语名 / 中文名 / 国家名（如输入 "Mali"、"刚果"、"德国"）
- **缩放平移**：滚轮缩放（以鼠标为中心）、拖拽平移、双击放大、右下角按钮复位；动态比例尺
- **渐进显示**：放大后显示城市（首府为红点加粗）与更多小区域标签
- **忠实复刻原图**：Mercator 投影、10° 经纬网、法语地名、海洋名、大河大湖、原图配色体系（每个列强按"获得时期"分深浅三档：1870 深 → 1900 中 → 1914 浅，色值直接取自原图图例色块）

## 目录结构

```
index.html       网页入口（index.html + style.css + app.js + data.js，零依赖）
scripts/         数据加工脚本（Python）
  build_data.py      从 1914 历史边界数据 + Natural Earth 生成 60 个区域
  postprocess.py     上色（原图图例解码）、面积计算、城市归属、重叠消解
  calibrate*.py      投影/配色校准（含原图色块解码）
  fidelity_check.py  与原图的海陆遮罩比对
data/            原始数据下载（world_1914.geojson、Natural Earth 各图层）
```

## 数据来源与准确性说明

- 边界主体来自开源历史边界数据集 [aourednik/historical-basemaps](https://github.com/aourednik/historical-basemaps) 的 1914 年世界地图，海岸线统一裁剪到 Natural Earth 50m
- 数据集粒度不足的三处按原图拆分/重建：
  - 法属西非（AOF）8 块殖民地、法属赤道非洲（AEF）4 块——以 1914 年外轮廓裁剪现代国界得到（原图即按此近似绘制）
  - 罗得西亚按赞比西河（今赞比亚/津巴布韦界）分为南北
  - 英属/意属索马里按历史边界重建（数据集形状有误）
- 毛里塔尼亚/尼日尔等撒哈拉腹地的 1914 年"南方领地"归属做了历史合理化分配
- 面积用球面多边形公式计算，总覆盖约 29.9M km²（非洲大陆约 30.4M，差额为海岸线简化与争议区）
- 利比亚按原图以奥斯曼青绿色标示（意土战争 1911–12 后意大利占领，原图未改为意大利色）
- 上沃尔特（1919 年才设立）等名称按原图的画法保留，以便与原图对照
