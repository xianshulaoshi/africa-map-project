# 非洲殖民扩张 1870–1914 · 交互地图

根据原始历史地图（Larousse 出版的法语地图 *L'Expansion coloniale en Afrique, 1870–1914*，见 `source-map.png`，673 × 710 px）**逐像素描摹**重绘的交互式网页。页面上的地图与原图同版：同一坐标系、同一版面（标题框、图例、比例尺都在原图位置）、实测的颜色与边界。

## 打开方式

直接双击打开 `index.html`（无需服务器、无需联网，字体已内嵌）。线上地址（GitHub Pages）：https://xianshulaoshi.github.io/africa-map-project/

## 与原图的一致程度（实测，不是 100%）

`scripts/trace_verify.py` 用无头 Chrome 把页面按 673 × 710 渲染，再与原图逐像素比较（每通道色差 ≤ 14/255 记为一致）：

| 像素范围 | 像素数 | 平均色差 /255 | 一致率（≤14） | ≤30 |
|---|---|---|---|---|
| 平涂区域（陆地、色块、边界线、海面） | 187,145 | 4.0 | **89.8%** | 93.8% |
| 文字周边 | 65,278 | 39.2 | 33.6% | 46.1% |
| 全图 | 477,830 | 11.6 | **78.6%** | 85.1% |

**结论：底图接近原图，但整体没有达到 100%。** 差距几乎全部在文字上。原因和现状：

- **字体不是原字体。** 原图用的是 Gill Sans（城市名、图例、区域标题）和一款很窄的粗体格罗特斯克体（领地名、标题），都是商业字体，不能嵌入网页。这里换成了外观最接近的开源字体（OFL 授权）：Questrial、IBM Plex Sans Condensed、Asap Condensed、Lato。字形宽度、笔画粗细和细节不同，标题还做了横向压缩，所以文字只能在"位置和大小对上"的程度上接近，做不到逐像素相同。
- **203 个标签中，138 个按原图墨迹拟合了字号、字距和位置**（相关系数 ≥ 0.5）；图例的 21 个文字按量到的位置显式给定，5 个手工定坐标；其余 39 个的墨迹和相邻的边线、城市点或另一行文字粘连，拟合不可靠，改为按识别框放置，位置有 1–3 px 的偏差（`Lagos`、`Le Cap`、`Port Elizabeth`、`OUGANDA`、`ORIENTALE` 等仍能看出偏移）。
- 斜体统一用 14° 斜切实现，与原图的 true italic 字形不同。

## 已知未做到的地方

- **河流只画出一部分**（72 条折线，尼罗河、尼日利亚和刚果盆地的主要河道），原图里其余细弱的支流没有提取出来。
- **经纬网点线没有画**：扫描件里它们太淡，测不出位置。赤道（细灰线）和两条回归线（淡虚线）画了。
- **没有画**：南非联盟内部的虚线分界（Transvaal / Natal / Zululand 等）、小领地名的引线（GAMBIE、GOLD COAST、SOMALIE FR. 等旁边的短线）。
- 独立国家（阿比西尼亚、利比里亚）底色是平涂，原图带极细的点状纹理。
- 1870 年边界（白色点线）是作为白色小色块描摹的，放大看是小方块而不是圆点。

## 功能

- **56 个可选中区域**：点选 / 多选、悬停提示（法语原名、中文名、面积、宗主国）、选中详情（地位、面积、今属）、右侧合计
- **图例筛选**：点图例里的列强，只高亮该国领地
- **搜索**：法语名 / 中文名 / 内部 id
- **缩放平移**：滚轮缩放、拖拽、双击放大、右下角按钮复位
- 侧面板默认在宽屏（≥1280 px）打开，可用左上角按钮收起；地图本身不受面板影响

## 点选范围的说明

原图在**法属西非和赤道非洲内部没有画边界**（阿尔及利亚撒哈拉、毛里塔尼亚、苏丹、尼日尔、乍得、上沃尔特，以及加蓬、中央刚果、乌班吉沙立是连成一片的同一颜色）。这些领地的点选范围是按图中名称的位置做近似划分的，只影响"点哪里选中谁"，不影响外观。南非联盟内的 Transvaal、Orange、Natal、Zululand、Basutoland、Swaziland、Kaffraria 和沃尔维斯湾同理。

  trace_fonts.sh                    下载 4 款开源字体到 scratch/（git 忽略）
  trace_segment.py                  逐像素分类：陆地各色档 / 白色边界线 / 海水，并量出各类色值
  trace_vector.py                   矢量化（陆地、色块、湖泊为洞）+ 用分水岭给色块归属领地
  trace_text.py (+ trace_ocr.swift) 定位全部文字和城市点；文字用 macOS 自带识别读取后人工订正
  trace_labels.py                   每个标签按原图墨迹拟合字体、字号、字距、位置
  trace_lines.py                    河流提取

## 描摹方法

- **分类**：每个像素归入一种平涂色档、海水或白色。白色边界线即使很淡（白度 ≥ 50%）也能识别；文字及其晕圈不参与，按周围颜色补齐，所以标签不会在色块上留下痕迹。
- **矢量**：各类色块在轻微平滑后的 0.5 等值线上描边，亚像素精度，无台阶。
- **海水**：近岸深、外海浅的晕染逐处不同（红海、地中海、毛里塔尼亚外海各不一样），无法用公式表达，按实测颜色做成 160 色的图层。
- **领地归属**：以白色边界线为障碍做分水岭——同一领地内的色档分界没有障碍，任何边界线都有，与领地大小无关。
